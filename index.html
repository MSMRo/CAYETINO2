🔌 Conexión de Hardware y Circuito Atenuador

Guía de conexionado para conectar el ESP32 a electrocardiógrafos, amplificadores de instrumentación y osciloscopios de forma segura.

1. Salida Directa del DAC del ESP32

  • Resolución: 8 bits discretos (256 niveles: 0 a 255).
  • Rango de Tensión: 0.0 V a 3.3 V.
  • Pines de salida DAC:
    • DAC 1: GPIO 25 (Predeterminado)
    • DAC 2: GPIO 26
    • Referencia: GND
  • Para conectar a un osciloscopio: sonda positiva a GPIO 25 y caimán de tierra a GND.

2. ¿Por qué se requiere un circuito atenuador?

Los biopotenciales humanos son de muy bajo voltaje: EKG: 1 - 3 mV, EMG: 0.1 - 5 mV, EEG: 10 - 100 µV. Dado que el DAC del ESP32 emite 3.3 V, si se conecta directamente a un amplificador de instrumentación (ej. AD620 o INA128 con ganancia G = 1000), saturaría de inmediato. Se utiliza un divisor resistivo pasivo 1:1000.

3. Diagrama Esquemático del Divisor Atenuador

ESP32 GPIO 25 (0 - 3.3V) │ ┌┴┐ │ │ R1 = 10 kΩ (10,000 Ω) └┬┘ │ ├───────────────────> Salida Atenuada (+) [~ 3.3 mV] │ Hacia electrodo EKG / Amplificador AD620 ┌┴┐ │ │ R2 = 10 Ω └┬┘ │ ESP32 GND ─────────────────> Tierra de Referencia (-) GND
Fórmula de Atenuación:
V_out = V_DAC × [ R2 / (R1 + R2) ] = 3.3V × (10 / 10010) ≈ 3.3 mV
